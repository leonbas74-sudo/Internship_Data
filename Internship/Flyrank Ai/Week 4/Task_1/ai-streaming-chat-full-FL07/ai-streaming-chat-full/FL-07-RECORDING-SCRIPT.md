# FL-07 Recording Script (~2 minutes, raw/unedited)

1. (0:00–0:15) Show terminal running `npm run dev`, then open http://localhost:3000 in browser.
2. (0:15–0:30) Briefly show the empty chat UI.
3. (0:30–0:45) Type: `Analyze https://example.com` and hit send/Enter.
4. (0:45–1:30) Let it stream. If the UI shows a tool-call/loading indicator, briefly narrate: "It's fetching the live page now."
5. (1:30–1:50) Show the final response containing the real title/description of example.com.
6. (1:50–2:00) State on camera: "That's the full loop — request, agent, live website fetch, and the real result."

No cuts, no edits. One continuous take.
