# Prompts Used

## Prompt 1 – Research (NotebookLM)

```
Read the uploaded document carefully.

Create a structured summary that includes:

1. Main concepts
2. Important definitions
3. Key points
4. Important examples
5. Frequently repeated topics
6. Possible exam questions

Use only information from the uploaded document.
Do not add outside information.
Present the output using headings and bullet points.
```

---

## Prompt 2 – Draft (ChatGPT)

```
You are an AI study assistant.

Convert the following research summary into professional study notes.

Requirements:
- Use clear headings and subheadings.
- Keep explanations short and easy to understand.
- Organize information using bullet points.
- Highlight important definitions.
- Create a Quick Revision section.
- Add 5 flashcards.
- Add 5 multiple-choice quiz questions with answers.
- Keep everything well-formatted and suitable for exam preparation.
```

---

## Prompt 3 – Review (ChatGPT)

```
You are acting as a quality reviewer.

Review these study notes for:

- Grammar and spelling
- Missing concepts
- Duplicate information
- Formatting consistency
- Readability

If improvements are needed, provide the corrected final version.
```
